# Настройка ADB и установка APK на Pixel 7 (Windows 10)

В этой инструкции описан полный цикл подключения Google Pixel 7 к Windows 10 по ADB, решение проблем с драйверами и обход ошибки безопасности при установке сторонних приложений.

## 1. Подготовка смартфона

1. Перейдите в **Настройки** -> **О телефоне**.
2. Быстро нажмите 7 раз на пункт **Номер сборки**, чтобы включить режим разработчика (потребуется ввод PIN-кода экрана блокировки).
3. Перейдите в **Настройки** -> **Система** -> **Для разработчиков**.
4. Включите тумблер **Отладка по USB**.
5. Чтобы избежать ошибки `INSTALL_FAILED_VERIFICATION_FAILURE` при установке APK без цифровой подписи Google Play, прокрутите ниже и **отключите** пункт **Проверять приложения по USB**.

## 2. Подготовка ПК (Windows 10)

1. Скачайте [SDK Platform-Tools](https://developer.android.com/studio/releases/platform-tools) и распакуйте архив в удобное место (например, `C:\platform-tools`).
2. Подключите телефон к ПК USB-кабелем (режим подключения на телефоне желательно перевести в **Передача файлов / Android Auto**).
3. Откройте папку `platform-tools` в Проводнике, введите `cmd` в адресную строку и нажмите Enter, чтобы открыть командную строку в этой директории.

## 3. Проверка подключения и драйверы

Выполните команду для проверки подключенных устройств:
```cmd
adb devices

Возможные статусы и решения:

    Пустой список (устройство не видно): В Windows отсутствует нужный драйвер.

        Скачайте архив Google USB Driver и распакуйте его.

        Откройте Диспетчер устройств Windows.

        Найдите ваш Pixel (обычно с желтым значком в "Другие устройства" или как ADB Interface).

        Нажмите ПКМ -> Обновить драйвер -> Найти драйверы на этом компьютере.

        Укажите путь к распакованной папке usb_driver и установите его.

    Статус unauthorized: Сработала защита Android.

        Включите экран смартфона.

        Во всплывающем окне "Разрешить отладку по USB?" поставьте галочку Всегда разрешать с этого компьютера и нажмите Разрешить.

При повторном вводе adb devices устройство должно отображаться со статусом device.
4. Установка приложения (APK)
adb install C:\путь\к\файлу\app.apk


Для установки скопируйте команду ниже, поставьте пробел и укажите путь к файлу (можно просто перетащить .apk файл мышкой прямо в окно командной строки):
DOS

При успешной установке в консоли появится сообщение Success.
Решение частых ошибок при установке

    INSTALL_FAILED_VERIFICATION_FAILURE: Install not allowed
    Сработала блокировка Play Protect. Убедитесь, что в меню разработчика выключен тумблер Проверять приложения по USB (см. шаг 1.5). Если ошибка сохраняется, откройте приложение Google Play -> профиль -> Play Защита -> настройки (шестеренка) -> временно отключите сканирование приложений.

    Обновление приложения с сохранением данных
    Если приложение уже установлено и его нужно обновить, используйте флаг -r:
    adb install -r app.apk
